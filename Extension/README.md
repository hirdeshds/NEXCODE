# NexCode

NexCode is an AI-powered VS Code extension that helps developers write, explain, fix, and review code directly in the editor.

## Features
- Inline code completions
- Code generation from comments or instructions
- Bug fixing with diff preview
- Code explanation
- Automated pipeline scan and PR workflow integration

## Setup
1. Install the extension from the VS Code Marketplace.
2. Ensure the NexCode backend is reachable at the configured backend URL.
3. Open the command palette and try the NexCode commands.

## Backend
The extension connects to a public NexCode backend service. If you are self-hosting, set the backend URL in the extension settings.
